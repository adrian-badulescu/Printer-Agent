Rev G:
15/11/2023
Changed the following wordings:
	Fiscal receipt to commercial document.
	Non-fiscal receipt to management document.
	document to invoice.
commandFormat updated to include H1=9.
recItemAdjustmentTypes: Added modifiers 10, 11 and 12 (Deposit, Free of Charge and Single use voucher).
invoiceMessageTypes: Added type 2 (trailer line) as they are now allowed in invoices.
paymentTypes: Added types 4, 5 and 6 (multiple tickets, not paid and payment discount).
paymentIndexRange: maxInclusive value increased from 10 to 99 as this is the limit with multiple tickets.
EJDataTypes: Added search type 6 (electronic payments only).
queryPrinterStatus removed from printerCommands file type (has to be printerCommand type).
justification: Increased maxInclusive from 2 to 4 (in case weighing scales function is used).
printBarCode: Extended codeTypes to allow numerical values from 65 to 78, 91, 92 and 95 (Data Matrix).
Added:
	printRecLotteryID
	getSerialNumber
	printRecRefundAdjustment
	deferredLotteryCodeLength
	rebootWebServer
Added printBarCode to printerFiscalDocument as they can now be printed in invoices.
commercialDocumentMessageIndexRange: minInclusive value reduced from 1 to 0 to allow static trailer lines erasure.
Added missing timeout attribute to printRecMessageFiscal, managementDocumentPrintRecMessage and printRecMessageInvoice.
Removed the following obsolete items:
	freeInvoice and receiptBasedFreeInvoice types from documentTypes.
	Free invoice documentAmount attribute from beginFiscalDocument.
	printFiscalDocumentLine from printerFiscalDocument and associated items:
		Attributes in <xs:complexType name="printFiscalDocumentLine">
		<xs:simpleType name="documentLineLength">
	operationType from endFiscalDocument and associated item:
		Attributes in <xs:simpleType name="operationTypes">
	saveDevices
	printRecTotalCreditNote
